# Rope Skipping Count 🏃‍♀️🪢

An interactive black-and-white jump rope counting story and coloring-book web app for children.

🔗 **Live Website**: [https://lucky-pluton.github.io/rope-skipping-count/](https://lucky-pluton.github.io/rope-skipping-count/)

---

## ✨ Features

- **Story & Comic Flow**: Follow the downward arrows from the playground to each count panel (1 to 5) and beyond.
- **Audio Synthesis (Web Audio API)**:
  - Realistic rope air whoosh (swept bandpass filter).
  - Ground thwack (asphalt snap transient).
  - Cheerful spring bounce (pitch pop).
- **Speech Synthesis**: Speaks numbers aloud ("One", "Two", "Three"...) and cheers ("Three skips!").
- **Interactive Practice Skipping Pad**: Kids can tap the **JUMP!** button or press the **Spacebar** to skip rope in real time and watch their personal record counter grow.
- **Printable Coloring Book**: Uses pure ink outlines on white paper (`@media print` ready) so parents and educators can print it as a physical coloring page.
- **Sharable**: Integrated Web Share API with one-click clipboard copying and social media preview tags.
